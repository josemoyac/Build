# Roles y permisos iniciales

| Rol        | Capacidades principales |
|------------|-------------------------|
| OrgAdmin   | Gestión completa de tenant, usuarios, empresas, licitaciones y conectores ERP. |
| Buyer      | Crear licitaciones, importar BC3, publicar, evaluar, adjudicar. |
| Vendor     | Consultar licitaciones invitadas, enviar y actualizar ofertas. |
| Approver   | Validar adjudicaciones y exportarlas al ERP. |
